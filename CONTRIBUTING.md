# Contributing

## Requirements

- Go 1.23 or later.
- `gofmt`, `go vet` and `go test` from the Go installation.
- No third-party dependency in the core.

## Setup

```powershell
git clone https://github.com/apantanella/dxf.git
cd dxf
go build ./...
go test ./...
```

## Before every commit

```powershell
gofmt -l .          # must print nothing
go vet ./...
go test ./...
go test -race ./...
```

If `gofmt -l .` lists a file, run `gofmt -s -w .` and repeat.

## Code conventions

- Exported names use `MixedCaps`; no underscores in identifiers.
- Packages `dxf` and `structural`: short names, without repeating the package
  name in the type name.
- Constructors: `New` for the primary type, `NewTypeName` when ambiguous.
- Options: `WithXxx` functions, with validation in the constructor.
- Errors: sentinels prefixed with `Err`, types suffixed with `Error`, messages
  in lowercase without a trailing punctuation mark.
- Small interfaces, defined where they are consumed.
- No `init()`, no mutable global state.
- Enumerations use a zero-value sentinel (`Unknown`, `Generic`).
- Consistent receivers for the whole lifetime of a type.
- All identifiers, comments, error messages and test messages are in English.

## Layout

| Path | Content |
| --- | --- |
| root | package `dxf`: DXF codec (R12 to R2018) |
| `tags/` | group code stream reader and writer |
| `structural/` | structural model and mapping |
| `docs/` | project documentation |
| `docs/decisions/` | architecture decision records (phases 0-6) |
| `docs/adr/` | architecture decision records of F1 |
| `testdata/` | fixtures, with declared provenance |

Dependency rule: `structural` imports `dxf`; the reverse is not allowed.

## Tests

- `*_test.go` files next to the code they verify.
- Table-driven tests with named subtests.
- Order-independent tests, with `t.Parallel()` where possible.
- Verify public behavior, not internal details.
- Fixtures in `testdata/`, never generated non-deterministically at runtime.
- Fuzz tests for the scanner and the parser.
- Benchmarks for parsing operations on large files.
- Integration tests with external files use the `integration` build tag.

```powershell
go test ./...
go test -run TestDecode ./...
go test -fuzz=FuzzDecode ./...
go test -tags=integration ./...
```

## Fixtures

Every fixture must declare its provenance in `testdata/README.md`:

- File generated by the library.
- File produced by an external CAD application, with application, version and
  date.
- Downloaded file, with URL and license.

Do not add third-party files whose license is incompatible with GPL-3.0.

## Commits

Commit messages are in English, imperative mood, with a type prefix:

```text
feat: add the section parser
fix: fix bulge decoding in vertices
docs: document the interoperability matrix
test: add a fixture for a closed POLYLINE
```

A commit contains one logical change. Update the `Unreleased` section of
`CHANGELOG.md` for every user-visible change.

## Pull request

Checklist:

- [ ] The change is covered by tests.
- [ ] `gofmt -l .` prints nothing.
- [ ] `go vet ./...` passes.
- [ ] `go test ./...` and `go test -race ./...` pass.
- [ ] The affected documentation is updated.
- [ ] `CHANGELOG.md` is updated.
- [ ] No third-party dependency was added without an ADR.
- [ ] Fixtures have declared provenance.
